# 🚖 OLA Ride Analytics Dashboard | Power BI

An interactive **Power BI dashboard** developed to analyze OLA ride booking data, monitor key business KPIs, and generate actionable insights through interactive visualizations.

---

## 📌 Overview

This project provides a comprehensive analysis of OLA ride booking data. The dashboard helps monitor ride performance, booking trends, cancellations, revenue, customer behavior, and operational metrics using interactive reports and filters.

---

## 🚀 Features

- 📈 Interactive Dashboard
- 🚖 Ride Booking Analysis
- 💰 Revenue & Booking Value Analysis
- ❌ Ride Cancellation Analysis
- 👥 Customer & Driver Insights
- 💳 Payment Method Distribution
- 📍 Vehicle Type Performance
- 📅 Daily & Monthly Booking Trends
- 🎯 Dynamic Filters & Slicers

---

## 📊 Key KPIs

- **Total Bookings**
- **Completed Rides**
- **Cancelled Rides**
- **Total Revenue**
- **Average Ride Value**
- **Cancellation Rate**

---

## 🛠️ Technologies Used

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
